## 📅 Patch Cycle

Game updates change memory offsets, which is why any tool needs refreshing.

| **Situation** | **What happens** | **What to do** |
| --- | --- | --- |
| **Minor patch** | Offsets may shift | Download the new build |
| **Major update** | Features temporarily removed | Wait for the rebuild |
| **Anti-cheat update** | Detection changes | Use the newest build only |
| **No update for weeks** | Build still current | Nothing — it still works |

**How to tell you need an update**

The menu opens but nothing takes effect, or the loader closes immediately after
the game starts. Both mean the offsets no longer match the running game.

**Why we rebuild instead of patching**

A rebuild re-signs the binary as well as fixing offsets, which is why it is
safer than applying a patch file to an old build.

**Keeping track**

The footer date on this page reflects the current build. If it is older than
the game's latest patch, check back.


## ⚡ Performance Tuning

The tool draws on top of the game, so badly configured visuals cost frames.
These settings keep the cost low.

| **Setting** | **Frame cost** | **Recommendation** |
| --- | --- | --- |
| **ESP boxes** | Low | Keep on |
| **Skeletons** | Medium | Off in busy fights |
| **Distance numbers** | Low | On |
| **Loot highlights** | Medium | On only when looting |
| **Radar** | Low | Keep on |
| **Full-screen ESP** | High | Avoid |

**Practical rules**

1. Turn off anything you are not actively looking at.
2. Keep the ESP distance limit around 200–300 m; rendering the whole map is
   wasted work.
3. If your frame rate drops in a crowded area, disable skeletons first.
4. Close the overlay when you do not need it — a hidden menu costs nothing.

**Hardware notes**

- 8 GB RAM is enough; the tool itself uses a few hundred MB.
- The overlay runs on the GPU, so a weak card benefits most from the settings
  above.
- Fullscreen exclusive can block drawing on some drivers — use borderless.
